# Расчёт деталей: металл · лазер · гибка

Браузерный калькулятор для быстрой оценки стоимости деталей из листа по DXF и PDF-чертежам.
Перетащили папку заказа → программа собрала данные из чертежей, подтянула цены металла с mc.ru
(Санкт-Петербург), отдала всё на проверку ИИ и показала три числа: **Себестоимость**, **Цену клиенту**
(с наценкой, по умолчанию 50 %) и **Выручку**, а также цену каждой детали с разбивкой на металл, резку,
гибку и доп. работы. Текст для письма клиенту копируется одной кнопкой.


## Запуск

Онлайн: https://metal.vectra-agency.tech — обновляется сам при push в `main` ([DEPLOY.md](DEPLOY.md)).

Нужен Node.js 23.6 или новее (проверено на 26).

```bash
cd calc
npm install        # один раз
npm run serve      # сборка + сервер → http://localhost:8787
```

Можно проще: двойной щелчок по `Запуск.command` (macOS) или `Запуск.bat` (Windows):
он сам установит зависимости, соберёт и откроет браузер.

Для разработки: `npm run dev` → http://localhost:5173 (горячая перезагрузка; API цен и ИИ тот же).

Без сервера (папка `dist/` на любом статическом хостинге) расчёт тоже работает, но цены
берутся из вшитого снимка `public/prices.json`, а шаги «Цены mc.ru» и «Анализ ИИ» пропускаются
с пояснением («Цены: снимок …», «Без ИИ»).

### ИИ-анализ

ИИ подключается на сервере через OpenAI-совместимый шлюз (по умолчанию Hubris, модель Claude Haiku 5.5).
Скопируйте `.env.example` в `.env` рядом с `package.json` и впишите `LLM_API_KEY` — `npm run dev` и
`npm start` прочитают файл сами. Проверка: `curl localhost:8787/api/ai/status` →
`{"configured":true,…}`. Ключи, лимиты, стоимость анализа (≈ 0,3–2 ₽, заказ из 7 позиций с чертежами —
≈ 0,6 ₽) и что делать при ошибках — в [DEPLOY.md, раздел «ИИ-анализ»](DEPLOY.md#ии-анализ).

Без ключа калькулятор работает как раньше: шаг «Анализ ИИ» пропускается, вместо него в списке
«Требует внимания» — подсказки по тексту чертежей и «Количество не сверено с заявкой».
Для разработки без расходов: `LLM_MOCK=1 npm run dev` — заглушка вместо модели (только для разработки).

## Как пользоваться

1. **Заявка клиента** (по желанию). Вставьте текст письма в поле «Заявка клиента» на первом экране —
   Ctrl+V работает в любом месте пустого экрана и пока идёт расчёт. ИИ сверит с ней количество и
   обозначения. Заявку можно добавить и позже: шапка → «Файлы» → «Заявка и документы».
2. **Файлы.** Перетащите папку заказа или файлы в любое место окна (или Ctrl+O, «Выбрать файлы»,
   «Выбрать папку»). Читаются DXF, PDF и `.txt`; остальное пропускается с уведомлением, а подробности —
   в «Журнале загрузки» (например: `.m3d` — сохраните как DXF или PDF; архивы `.rar/.zip` — распакуйте;
   `.xls` — скопируйте текст заявки). Имя папки становится названием заказа. Если в заказе уже есть
   позиции, окно делится пополам: слева — «Добавить к заказу» (весь заказ пересчитается заново, с новым
   анализом ИИ), справа — «Новый заказ» (текущий можно вернуть в течение 15 секунд).
3. **Ход расчёта.** Экран показывает четыре шага со временем и подробностями: «Файлы» (сколько файлов →
   позиций), «Цены mc.ru» (обновляются только материалы и толщины заказа, если цены старше суток),
   «Анализ ИИ» (модель, прошедшее время; обычно 10–60 с) и «Расчёт». После цен уже видна
   предварительная сумма. «Показать расчёт без ИИ» открывает результат сразу — анализ доходит в фоне
   и сам ничего не меняет: появится «Анализ ИИ готов» с кнопкой «Применить рекомендуемые».
   «Отменить анализ» останавливает его.
4. **Итог заказа** — три карточки в одну строку-формулу:
   - **Себестоимость** — что платим мы: металл + резка + гибка + доп. работы + доставка;
   - **Цена клиенту** — себестоимость × (1 + наценка); эту сумму платит клиент, она же в КП, тексте
     письма и CSV. Наценка: 30 / 50 / 70 / 100 % или своя; «Сценарии» сравнивают наценки и подбирают
     наценку под нужную цену;
   - **Выручка** — цена клиенту − себестоимость, то есть сколько заказ приносит сверх затрат,
     и маржа в % от цены.

   Все суммы с НДС 22 %, рядом — суммы без НДС. Ниже — доли металла, резки, гибки и доп. работ,
   число позиций, штук, килограммов, метров реза, гибов и листов. При прокрутке итог сворачивается
   в узкую полосу под шапкой.
5. **Анализ ИИ.** ИИ проверяет каждую позицию по чертежам, тексту штампа и технических требований,
   заявке, ценам mc.ru и расценкам: материал и толщина по штампу (Ст3 по ГОСТ 19904 → 08пс х/к,
   К-ПУ-3 → рифлёный), количество по заявке, гибы, доп. операции (покраска, резьба, сварка…),
   незаказанные исполнения и дубли. Карточка «Анализ ИИ» — итог, уверенность, модель, время и цена
   анализа, «Требует внимания», «Вопросы клиенту», риски и рекомендации, «Что видел ИИ».
   - Предложения ИИ не меняют исходные данные: принятое накладывается поверх и помечено «✦ ИИ»
     (щелчок — «Вернуть»). Сами применяются только очевидные: количество, материал и толщина, если в
     файлах их не нашлось, гибы, если в чертеже не найдено ни одного, и доп. операции по ставкам из
     «Расценок». Остальное ждёт решения: «Принять» / «Отклонить» или «Принять все предложения» сразу.
     «Исключить из расчёта» (незаказанное исполнение, дубль) — всегда только по решению менеджера.
   - **«Разобрать по очереди»** открывает замечания одно за другим рядом с таблицей: «Принять»,
     «Отклонить» или «Верно» сразу переходят к следующему (J/K или ↓/↑), в конце —
     «Все замечания разобраны».
   - «ИИ изменил цену клиенту: ±… ₽» и «Отменить изменения ИИ» показывают и снимают влияние ИИ целиком.
   - Если после анализа изменить то, что видел ИИ (количество, материал, файлы…), анализ помечается
     «Устарел» с кнопкой «Обновить анализ ИИ»; сам он не перезапускается. Наценка, доставка и название
     на это не влияют.
6. **Вкладки результата:**
   - **«Позиции»** — таблица с правкой прямо в ячейках: материал, толщина (в т. ч. своя, «2,7»),
     количество, гибы × длина гиба (Enter — то же поле ниже, Esc — вернуть). Не найденное в файлах
     выделено жёлтой пунктирной рамкой. Поиск («/»), фильтры («Требуют внимания», «Изменены ИИ», «Без цены»,
     «Исключены»), сортировка, «Колонки» (эскиз; габарит, масса, рез; гибы; металл, резка, гибка, доп. на 1 шт;
     себестоимость за шт; доля в заказе).
     Галочки → панель массовой правки (материал, толщина, гибы, количество, включить/исключить, удалить
     с «Вернуть»). Щелчок по строке открывает **карточку позиции** сбоку (таблица остаётся доступной,
     ↑/↓ — соседняя позиция): замечания и анализ ИИ, параметры с происхождением значения (имя файла,
     штамп PDF, ИИ, вручную), чертёж / контур / текст чертежа, «Как получилась цена» по шагам,
     доп. работы с готовыми ставками, примечание, «Дублировать», «Исключить из расчёта», «Удалить».
   - **«Металл и раскрой»** — по каждой группе «материал + толщина»: выбор листа (авто или формат с
     ценой), своя цена ₽/кг, списание («по раскрою», «целыми листами», «по габариту + отход»), раскладка
     деталей по листам; наведение на деталь подсвечивает её в списке и наоборот.
   - **«Цены mc.ru»** — какие предложения mc.ru взяты для каждой группы, ссылки, даты цен,
     «Обновить цены заказа».
   - **«Для клиента»** — коммерческое предложение так, как его увидит клиент, «Перед отправкой»
     (что ещё не проверено), округление цены за шт (до копеек / рубля / 10 ₽), срок действия, условия.
7. **«Скопировать для клиента»** (в шапке, в полосе итога, на вкладке «Для клиента», на телефоне —
   внизу экрана) кладёт в буфер текст для письма: позиции, количество, цена за шт, суммы, итог с НДС —
   без себестоимости и наценки. В меню рядом: «Скопировать таблицей (для Excel)», «Скопировать с
   вопросами клиенту», «Excel для клиента (CSV)». Позиции без размеров попадают в текст как «цена
   уточняется» и в итог не входят. Если в расчёте остались ошибки, программа сначала спросит.
8. **Печать.** Ctrl+P на любой вкладке печатает КП на А4 (шапка и подпись — «Расценки» → «КП и цены»).
   В меню ⋯: «Печать расчёта (внутр.)» — с себестоимостью и разбивкой, «Excel: внутренний расчёт» (CSV).
9. **Расценки** (кнопка в шапке): «Резка», «Гибка» (с множителями длины гиба и наладкой), «Материалы»
   (множители резки и гибки, списание), «Раскрой и НДС» (перемычка, поле, потолки отхода, НДС),
   «Доп. операции» (ставки покраски, резьбы, сварки… — по ним считает и ИИ), «КП и цены» (шапка,
   подпись, условия, срок действия, через сколько часов обновлять цены mc.ru). «Сбросить» — с «Вернуть»;
   расценки можно сохранить в файл и загрузить на другом компьютере.
10. **Новый заказ** — ⋯ → «Новый заказ» (15 секунд можно «Вернуть»). Заказ, расценки и настройки КП
    сохраняются в браузере сами, PDF — в IndexedDB, чтобы чертёж открывался после перезагрузки.

Горячие клавиши (⋯ → «Горячие клавиши» или «?»): Ctrl+O — файлы, Ctrl+P — печать КП, «/» — поиск по
позициям, Esc — сначала вернуть значение поля, потом закрыть панель; на macOS вместо Ctrl — ⌘.

Работает на компьютере (основной сценарий, широкая таблица), на планшете и на телефоне (позиции —
карточками, «Скопировать для клиента» внизу). Светлая и тёмная тема — как в системе.

### Имена файлов

Из имени файла подставляются материал, толщина и количество — формат как у подготовленных файлов:
`НГЭН.745421.0001 st3 s2mm 5sht.dxf` (`st3`, `09g2s`, `08ps`, `rifleniy/romb`, `amg2`, `08x18h10t`,
`aisi304`, `ocink`…; `s1,5mm`; `20sht`). Чего нет ни в имени, ни в штампе PDF — подсвечено жёлтым и
попадает в «Требует внимания».

**Гибы.** В PDF линии гиба находятся сами. В подготовленных к резке DXF их обычно нет — тогда гибы
вводятся вручную, или положите рядом PDF той же детали: гибы возьмутся из него.

## PDF-чертежи

Поддерживаются векторные PDF из САПР (КОМПАС, AutoCAD и т.п.) по ЕСКД — как в `projects/2–4`.
По каждому чертежу программа:

- **находит развёртку**: собирает замкнутые контуры по каждой толщине линий, отбрасывает
  рамку, штамп, таблицы, значок штриховки материала; выбирает вид по метке «(1:5)»,
  совпадению с проставленными размерами и массе; изометрию отбрасывает;
- **определяет масштаб** из метки вида или штампа и проверяет его по размерам на чертеже;
- **читает штамп**: обозначение, материал (Ст3, 08пс, 09Г2С, АМг2, 12Х18Н10Т…), толщину
  («2 ГОСТ 19904-90», «К-ПУ-3», «s2»), массу. Ст3 по ГОСТ 19904 (холоднокатаный) → 08пс х/к;
- **сверяет массу** по контуру с массой на чертеже — значок «✓ масса» в строке таблицы. Это
  главная проверка, что вид и масштаб угаданы верно; расхождение попадает в «Требует внимания».
  Если в чертеже масса посчитана как для стали (бывает у алюминиевых деталей), это учитывается;
- **таблица исполнений** (L, A, C, D…, масса): размеры исполнения подставляются в контур.
  Исполнение берётся из имени файла, его можно сменить в карточке позиции;
- **вид с обрывом**: недостающая длина вставляется в месте обрыва (по таблице или по
  габаритному размеру на чертеже), а не растягивает весь вид;
- **линии гиба**: штрихпунктир с двумя точками (по ЕСКД); если таких нет —
  штрихпунктир/штрихи поперёк всей детали. Длина гиба — по контуру;
- **собирает весь текст чертежа** (штамп, технические требования, примечания, таблицы) — его
  получает ИИ; в карточке позиции он виден на вкладке «Текст чертежа».

Карточка позиции → «Открыть чертёж и проверить»: страница PDF с подсвеченными найденными
видами. Можно щёлкнуть другой вид, сменить масштаб или исполнение и сразу увидеть габарит,
площадь, рез и сверку массы. «Габарит вручную» (в строке — «Задать габарит») — если контур
не распознался (например, скан).

Несколько чертежей в одном PDF разбираются по листам (новое обозначение в штампе — новая
деталь; второй лист без штампа присоединяется к первому).

**Заявка в PDF.** Листы без чертежа (заявка, спецификация, счёт) читаются как список
«обозначение … N шт»: количество проставляется найденным позициям, а их текст, как и `.txt`,
сохраняется в «Документах» заказа и уходит ИИ. Если в заявке перечислены исполнения
(`…-0700 — 5 шт`, `…-1700 — 10 шт`), а прислан один чертёж с таблицей исполнений, позиции по
каждому исполнению создаются сами, базовая исключается. Заявку свободным текстом («Прошу счёт…
БВС-305Х300.000 — 3 шт») программа сама не разбирает — это делает ИИ.

**DXF + PDF одной детали** (совпало обозначение) — одна позиция: контур из DXF, гибы,
материал и сверка массы — из PDF.

## Как считается цена

Деньги считает код, а не ИИ: ИИ только проверяет входные данные и предлагает правки.

| Статья | Формула |
|---|---|
| **Металл** | Детали одного материала и толщины укладываются на листы по габаритам (MaxRects, с поворотом, перемычка 8 мм, поле 10 мм). Стоимость = листы × масса листа × цена ₽/кг с mc.ru. Последний лист — по занятому прямоугольнику (остаток деловой). Отход ограничен 40 % к массе габаритных заготовок — неудобные детали цех докладывает к чужим заказам. Металл группы делится между деталями пропорционально габаритной площади. |
| **Резка** | длина реза (все контуры) × ₽ за погонный метр по прайсу лазерной резки: строка — по толщине (толщина без своей строки — по ближайшей большей), колонка — по материалу (сталь чёрная, нержавейка, алюминий, медь/латунь). Врезки отдельно не оплачиваются. Прайс — «Расценки» → «Резка», его можно загрузить из CSV. |
| **Гибка** | гибы × ₽/гиб по толщине × множитель длины гиба (≤0,3 м ×0,8; ≤1 м ×1; ≤2 м ×1,4; ≤3 м ×1,8; >3 м ×2,5). |
| **Доп. работы** | на позицию, ₽/шт: вручную или по ставкам «Доп. операций» (например, порошковая покраска — 2 стороны × площадь × ₽/м²); их же предлагает ИИ по тексту чертежа. |
| **Себестоимость** | металл + резка + гибка + доп. работы + доставка. |
| **Цена клиенту** | цена за шт = себестоимость за шт × (1 + наценка %), округлённая как в КП (по умолчанию до рубля); сумма строки = цена за шт × количество; итог = сумма строк + доставка с наценкой. Ровно эта сумма — в КП, тексте для клиента, печати и CSV. Все цены с НДС 22 %. |
| **Выручка** | цена клиенту − себестоимость; маржа = выручка ÷ цена клиенту. |

Списание металла настраивается по материалу: «по раскрою» (Ст3, 09Г2С, 08пс, рифлёный,
оцинковка), «целыми листами» (нержавейка, алюминий — цех докупает листы),
«по габариту + отход».

Деталь длиннее листа автоматически считается из нескольких частей (+ рез по стыку) —
так делает и цех («из двух частей»). Автовыбор листа предпочитает форматы, где деталь
влезает целиком.

Все расценки редактируются в «Расценках»; их можно сохранить в файл и загрузить на
другом компьютере.

## Цены mc.ru

- Сервер берёт выборки `mc.ru/region/speterburg/metalloprokat/<раздел>/r1/<толщина>`,
  отбирает листы нужной марки со склада в Санкт-Петербурге и берёт медиану цены
  «от 1 т» по каждому формату листа.
- При каждом расчёте обновляются только материалы и толщины текущего заказа, и только если
  их цены старше суток («Расценки» → «КП и цены»). Вручную — «Обновить цены заказа» на вкладке
  «Цены mc.ru». Весь справочник: `npm run prices` (≈2 мин), отдельные материалы:
  `npm run prices -- amg2 amg2r`.
- mc.ru включает проверку «я не робот» при частых запросах. Поэтому запросы идут по
  одному с паузой, а при срабатывании проверки обновление останавливается, уже
  полученные цены сохраняются, а повтор доступен через 15 минут («Можно повторить в …»).
  Расчёт при этом не останавливается — по сохранённым ценам.
- Цены хранятся в `data/prices.json` (рабочие) и `public/prices.json` (снимок в сборке).
- Если толщины нет на складе, берётся цена ближайшей толщины — это оценка, она попадает в
  «Требует внимания». Свою цену ₽/кг можно вписать в карточке группы на вкладке «Металл и раскрой».

## Ограничения

- Только ASCII DXF (R12–2018). Бинарный DXF и DWG — пересохраните в DXF.
- PDF — только векторный. Скан (картинка) добавляется позицией с пометкой «Нет размеров (скан)»:
  габарит вводится вручную («Задать габарит»), чертёж при этом виден; до этого позиция в итог не входит.
- Распознавание PDF рассчитано на чертежи по ЕСКД (штамп справа внизу, метки видов,
  таблицы исполнений). Чертёж в нестандартном оформлении проверьте в окне «Открыть
  чертёж и проверить» — без подтверждения массой позиция помечается предупреждением.
- Раскрой — оценка по габаритам: для Г-образных и фигурных деталей реальный раскрой
  плотнее (это частично компенсирует потолок отхода).
- Рамки чертежа и штампы отбрасываются автоматически (замкнутый контур с текстом
  внутри или формат A4–A0); в превью они показаны серым пунктиром — проверьте.
- Если в файле несколько отдельных контуров, они считаются одним комплектом на 1 шт.
- ИИ может ошибаться: каждое его изменение видно («✦ ИИ») и отменяется, цитаты из заявки и чертежа
  помечены ✓ (нашлись в документах) или ? (не нашлись). Документ, который на самом деле не заявка
  (например, счёт или прайс цеха с «N шт»), ИИ может принять за заявку — проверьте количество.
  ИИ смотрит не больше 150 позиций заказа и до 12 изображений чертежей.
- Анализ ИИ на сервере живёт 30 минут и не переживает перезапуск сервера; сохранённый в браузере
  результат остаётся, а «Что видел ИИ» — только до перезагрузки страницы.
