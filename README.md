# Расчёт деталей: металл · лазер · гибка

Браузерный калькулятор для быстрой оценки стоимости деталей из листа по DXF и PDF-чертежам.
Перетащили файлы или папку → получили цену за каждую деталь и по заказу, с разбивкой
на металл, резку, гибку и доп. работы. Цены металла берутся с mc.ru (Санкт-Петербург).

## Запуск

Онлайн: https://metal.vectra-agency.tech — обновляется сам при push в `main` ([DEPLOY.md](DEPLOY.md)).

Нужен Node.js 23.6 или новее (проверено на 26).

```bash
cd calc
npm install        # один раз
npm run serve      # сборка + сервер → http://localhost:8787
```

Можно проще: двойной щелчок по `Запуск.command` (macOS) или `Запуск.bat` (Windows):
он сам установит зависимости, соберёт и откроет браузер.

Для разработки: `npm run dev` → http://localhost:5173 (горячая перезагрузка, API цен тот же).

Без сервера (папка `dist/` на любом статическом хостинге) всё тоже работает, но цены
берутся из вшитого снимка `public/prices.json` и кнопки «Обновить» нет.

## Как пользоваться

1. Перетащите DXF и/или PDF-чертежи (можно сразу всю папку заказа). m3d и прочее
   пропускаются. Архивы `.rar/.zip` сначала распакуйте. Про PDF — раздел ниже.
2. Из имени файла подставляются материал, толщина и количество — формат как у
   подготовленных файлов: `НГЭН.745421.0001 st3 s2mm 5sht.dxf`
   (`st3`, `09g2s`, `08ps`, `rifleniy/romb`, `amg2`, `08x18h10t`, `aisi304`, `ocink`…;
   `s1,5mm`; `20sht`). Что не распознано — подсвечено жёлтым.
3. Проверьте **число гибов** и длину гиба. В PDF линии гиба находятся сами. В
   подготовленных к резке DXF их обычно нет — тогда гибы вводятся вручную, или
   положите рядом PDF той же детали: гибы возьмутся из него.
4. Готово: цена за штуку и сумма по каждой позиции, итог по заказу, раскрой по листам.
   Щелчок по детали открывает пошаговый расчёт «как получилась цена».
5. Наценка (по умолчанию 50 %, любое значение) и доставка — в блоке итога. Наценка входит
   в цену за штуку, сумму по позиции и итог; колонки «Металл», «Резка», «Гибка», «Доп.» —
   себестоимость. Выгрузка: «Excel (CSV)» и «Печать» (в PDF).

Пакетная правка: отметьте строки галочками — внизу появится панель для смены
материала, толщины, гибов и количества сразу у всех.

Заказ и расценки сохраняются в браузере автоматически.

## PDF-чертежи

Поддерживаются векторные PDF из САПР (КОМПАС, AutoCAD и т.п.) по ЕСКД — как в `projects/2–4`.
По каждому чертежу программа:

- **находит развёртку**: собирает замкнутые контуры по каждой толщине линий, отбрасывает
  рамку, штамп, таблицы, значок штриховки материала; выбирает вид по метке «(1:5)»,
  совпадению с проставленными размерами и массе; изометрию отбрасывает;
- **определяет масштаб** из метки вида или штампа и проверяет его по размерам на чертеже;
- **читает штамп**: обозначение, материал (Ст3, 08пс, 09Г2С, АМг2, 12Х18Н10Т…), толщину
  («2 ГОСТ 19904-90», «К-ПУ-3», «s2»), массу. Ст3 по ГОСТ 19904 (холоднокатаный) → 08пс х/к;
- **сверяет массу** по контуру с массой на чертеже — значок «PDF ✓ масса» в строке. Это
  главная проверка, что вид и масштаб угаданы верно. Если в чертеже масса посчитана как для
  стали (бывает у алюминиевых деталей), это учитывается;
- **таблица исполнений** (L, A, C, D…, масса): размеры исполнения подставляются в контур.
  Исполнение берётся из имени файла, его можно сменить в карточке позиции;
- **вид с обрывом**: недостающая длина вставляется в месте обрыва (по таблице или по
  габаритному размеру на чертеже), а не растягивает весь вид;
- **линии гиба**: штрихпунктир с двумя точками (по ЕСКД); если таких нет —
  штрихпунктир/штрихи поперёк всей детали. Длина гиба — по контуру.

Карточка позиции → «Открыть чертёж и проверить»: страница PDF с подсвеченными найденными
видами. Можно щёлкнуть другой вид, сменить масштаб или исполнение и сразу увидеть габарит,
площадь, рез и сверку массы. «Габарит вручную» — если контур не распознался (например, скан).

Несколько чертежей в одном PDF разбираются по листам (новое обозначение в штампе — новая
деталь; второй лист без штампа присоединяется к первому).

**Заявка в PDF.** Листы без чертежа (заявка, спецификация, счёт) читаются как список
«обозначение … N шт»: количество проставляется найденным позициям. Если в заявке
перечислены исполнения (`…-0700 — 5 шт`, `…-1700 — 10 шт`), а прислан один чертёж с
таблицей исполнений, позиции по каждому исполнению создаются сами, базовая исключается.

**DXF + PDF одной детали** (совпало обозначение) — одна позиция: контур из DXF, гибы,
материал и сверка массы — из PDF.

Исходные PDF хранятся в браузере (IndexedDB), чтобы чертёж открывался после перезагрузки.

## Как считается цена

| Статья | Формула |
|---|---|
| **Металл** | Детали одного материала и толщины укладываются на листы по габаритам (MaxRects, с поворотом, перемычка 8 мм, поле 10 мм). Стоимость = листы × масса листа × цена ₽/кг с mc.ru. Последний лист — по занятому прямоугольнику (остаток деловой). Отход ограничен 40 % к массе габаритных заготовок — неудобные детали цех докладывает к чужим заказам. Металл группы делится между деталями пропорционально габаритной площади. |
| **Резка** | длина реза (все контуры) × ₽/м по толщине + врезки (число контуров) × ₽/врезку. Для 09Г2С, нержавейки, алюминия — множитель. |
| **Гибка** | гибы × ₽/гиб по толщине × множитель длины гиба (≤0,3 м ×0,8; ≤1 м ×1; ≤2 м ×1,4; ≤3 м ×1,8; >3 м ×2,5). |
| **Доп. работы** | вручную на позицию: вальцовка, сварка, покраска и т.п., ₽/шт. |
| **Итог** | (сумма + доставка) × (1 + наценка %). Все цены с НДС 22 %. |

Списание металла настраивается по материалу: «по раскрою» (Ст3, 09Г2С, 08пс, рифлёный,
оцинковка), «целыми листами» (нержавейка, алюминий — цех докупает листы),
«по габариту + отход».

Деталь длиннее листа автоматически считается из нескольких частей (+ рез по стыку) —
так делает и цех («из двух частей»). Автовыбор листа предпочитает форматы, где деталь
влезает целиком.

Все расценки редактируются в «Расценках»; их можно сохранить в файл и загрузить на
другом компьютере.

## Цены mc.ru

- Сервер берёт выборки `mc.ru/region/speterburg/metalloprokat/<раздел>/r1/<толщина>`,
  отбирает листы нужной марки со склада в Санкт-Петербурге и берёт медиану цены
  «от 1 т» по каждому формату листа.
- Кнопка «Обновить» в шапке обновляет только материалы и толщины текущего заказа
  (несколько запросов). Весь справочник: `npm run prices` (≈2 мин),
  отдельные материалы: `npm run prices -- amg2 amg2r`.
- mc.ru включает проверку «я не робот» при частых запросах. Поэтому запросы идут по
  одному с паузой, а при срабатывании проверки обновление останавливается, уже
  полученные цены сохраняются — повторите через 10–15 минут.
- Цены хранятся в `data/prices.json` (рабочие) и `public/prices.json` (снимок в сборке).
- Если толщины нет на складе, берётся цена ближайшей толщины (помечено жёлтым).
  Свою цену ₽/кг можно вписать в карточке группы в разделе «Металл и раскрой».

## Ограничения

- Только ASCII DXF (R12–2018). Бинарный DXF и DWG — пересохраните в DXF.
- PDF — только векторный. Скан (картинка) добавляется позицией с пометкой: габарит
  вводится вручную («Габарит вручную» в карточке), чертёж при этом виден.
- Распознавание PDF рассчитано на чертежи по ЕСКД (штамп справа внизу, метки видов,
  таблицы исполнений). Чертёж в нестандартном оформлении проверьте в окне «Открыть
  чертёж» — без подтверждения массой позиция помечается предупреждением.
- Раскрой — оценка по габаритам: для Г-образных и фигурных деталей реальный раскрой
  плотнее (это частично компенсирует потолок отхода).
- Рамки чертежа и штампы отбрасываются автоматически (замкнутый контур с текстом
  внутри или формат A4–A0); в превью они показаны серым пунктиром — проверьте.
- Если в файле несколько отдельных контуров, они считаются одним комплектом на 1 шт.

## Устройство

```
src/core/dxf.ts        парсер DXF: LINE, ARC, CIRCLE, (LW)POLYLINE с bulge, SPLINE, ELLIPSE, блоки
src/core/geometry.ts   сборка контуров, отверстия, рамки, линии гиба, длина реза, площадь
src/core/nesting.ts    раскладка на листы (MaxRects)
src/core/materials.ts  материалы, плотности, правила mc.ru, разбор имени файла
src/core/pricing.ts    модель цены и расценки по умолчанию
src/core/pdf.ts        чтение векторного PDF через pdf.js: линии с толщиной, текст (мм листа)
src/core/pdfAnalyze.ts распознавание: штамп, таблица исполнений, выбор вида и масштаба, обрывы, гибы, заявки
src/pdfImport.ts       импорт PDF в браузере, сверка массы, просмотр страницы
src/merge.ts           слияние DXF + PDF + заявки
server/mc.ts           парсер mc.ru
server/api.ts          /api/prices, /api/prices/refresh
src/components/…       интерфейс (React)
scripts/               analyze / analyze-pdf (разбор по папке), calibrate (сверка), update-prices
```

Ядро (`src/core`) не зависит от браузера — те же модули запускаются в Node:
`npm run analyze -- <папка с DXF>`.
